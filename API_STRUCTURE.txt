┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. Extract HTML API                                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ Endpoint:  POST /extract-html                                               │
│ Input:     {"url": "https://example.com"}                                   │

│ Use:       Fetch raw HTML from URL                                          │

┌─────────────────────────────────────────────────────────────────────────────┐
│ 2. Clean HTML API                                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│ Endpoint:  POST /clean-html                                                 │
│ Input:     {"html": "<html>...</html>"}                                     │
│ Output:    {"text": "...", "title": "..."}                                  │
│ Use:       Extract main content from HTML                                   │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 3. Extract Opinions API ⭐                                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│ Endpoint:  POST /extract-opinions                                           │
│ Input:     {"text": "..."}                 │
│ Output:    {                                                                │
│              "atomic_opinions": [                                           │
│                {                                                            │
│                  "text": "Opinion text",                                    │
│                  "bias_probabilities": {                                    │
│                    "left": 0.6, "right": 0.2, "neutral": 0.2               │
│                  }                                                          │
│                }                                                            │
│              ],                                                             │
│              "overall_bias_distribution": {...}                             │
│            }                                                                │
│ Use:       Analyze text for atomic opinions with bias scores                │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 4. Complete Analysis API ⭐⭐                                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ Endpoint:  POST /analyze                                                    │
│ Input:     {"url": "https://example.com"} │
│ Output:    Same as Extract Opinions API                                     │
│ Pipeline:  URL → HTML → Clean Text → Atomic Opinions → Bias Scores         │
│ Use:       One-step complete analysis (RECOMMENDED)                         │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. Bias Score API ⭐⭐⭐                                                     │
├─────────────────────────────────────────────────────────────────────────────┤
│ Endpoint:  POST /bias-score                                                 │
│ Input:     {"url": "https://example.com"}  OR  {"content": "text..."}      │
│            - url: URL to fetch and analyze (supports MBFC, caching)        │
│            - content: Direct text content to analyze (no URL fetching)     │
│            - title: Optional title (used when content is provided)          │
│            - mode: "LOCAL_CHAIN", "NO_CHAIN", or "PURE_ONLINE"              │
│            - use_mbfc: Whether to use MBFC database (only for URL)          │
│            - use_few_shots: Whether to use few-shot examples                  │
│ Output:    {                                                                │
│              "url": "https://example.com" or null,                          │
│              "content_provided": true/false,                                │
│              "overall_bias_distribution": {                                 │
│                "left": 0.45, "right": 0.35, "neutral": 0.20,               │
│                "dominant_bias": "left", "bias_score": -0.1                  │
│              },                                                             │
│              "opinions_count": 5,                                           │
│              "facts_count": 3                                               │
│            }                                                                │
│ Use:       Quick bias check without opinion details (FASTEST)               │
│            Supports both URL fetching and direct content analysis            │
└─────────────────────────────────────────────────────────────────────────────┘

                          Response Structure
═══════════════════════════════════════════════════════════════════════════════

Bias Probability Distribution (per opinion & overall):
{
  "left": 0.45,          // Progressive bias probability (0.0-1.0)
  "right": 0.35,         // Conservative bias probability (0.0-1.0)
  "neutral": 0.20,       // Neutral/Centrist probability (0.0-1.0)
  "dominant_bias": "left", // Category with highest probability
  "bias_score": -0.1     // Single score: -1.0 (left) to +1.0 (right)
}

Atomic Opinion Structure:
{
  "text": "Support for universal healthcare",
  "opinion_type": {"value": "opinion", "code": 1},  // fact=0, opinion=1
  "bias_probabilities": {...},
  "original_sentence": "I strongly support universal healthcare",
  "confidence": 0.9,
  "reasoning": "This expresses support for..." // Optional (with CoT)
}

                              Quick Examples
═══════════════════════════════════════════════════════════════════════════════

1. Quick Bias Check (with URL):
   curl -X POST http://localhost:8000/api/v1/opinion/bias-score \
     -H "Content-Type: application/json" \
     -d '{"url": "https://example.com/article"}'

1b. Quick Bias Check (with Content):
   curl -X POST http://localhost:8000/api/v1/opinion/bias-score \
     -H "Content-Type: application/json" \
     -d '{"content": "This article discusses political policies...", "title": "Article Title"}'

2. Complete Analysis:
   curl -X POST http://localhost:8000/api/v1/web-opinion/analyze \
     -H "Content-Type: application/json" \
     -d '{"url": "https://example.com/article"}'

3. Python Example (URL):
   import requests
   response = requests.post(
       "http://localhost:8000/api/v1/opinion/bias-score",
       json={"url": "https://example.com/article"}
   )
   result = response.json()
   print(f"Bias: {result['overall_bias_distribution']['dominant_bias']}")

3b. Python Example (Content):
   import requests
   response = requests.post(
       "http://localhost:8000/api/v1/opinion/bias-score",
       json={
           "content": "This article discusses political policies and their impact...",
           "title": "Political Analysis",
           "mode": "LOCAL_CHAIN",
           "use_few_shots": True
       }
   )
   result = response.json()
   print(f"Bias: {result['overall_bias_distribution']['dominant_bias']}")
   print(f"Content provided: {result['content_provided']}")

     -d '{"title": "Advanced Python Help"}'

═══════════════════════════════════════════════════════════════════════════════
                          Privacy Types & Severity
═══════════════════════════════════════════════════════════════════════════════

Privacy Types:
- personal_identifiers: Names, usernames, nicknames
- contact_info: Phone numbers, emails, addresses
- government_ids: SSN, passport, driver's license
- financial_accounts: Bank accounts, credit cards, transactions
- health_records: Medical conditions, prescriptions, test results
- authentication_credentials: Passwords, API keys, tokens
- precise_location: GPS coordinates, exact addresses
- messaging_content: Chat logs, private communications
- social_security: Social security information
- relationship_data: Family information, social connections
- behavioral_data: Usage patterns, preferences

Severity Levels:
- low: Publicly available or low-risk information
- medium: Personal but commonly shared information
- high: Sensitive personal or financial information
- critical: Government IDs, full financial access, life-critical data

Confidence Levels:
- high: All detected items validated against original messages
- medium: Some items validated or strong pattern corroboration
- low: Pattern-based detection only, no location validation
- invalid: No detected items found in original messages (LLM hallucination)

   import requests

The Few-Shot Management API provides centralized configuration for few-shot examples across all AI agents. Few-shot examples help guide LLM behavior by providing example inputs and outputs.

Supported Agents:
- summarizer: Conversation summarization agent
- demographic-evaluator: Sentence evaluation from demographic perspectives
- nudge-collapse: 4-turn radicalization protocol agent
- bot-creator: Bot creation and configuration agent
- content-extractor: Academic content extraction from web pages
- claim-atomizer: Atomic claim decomposition from text
- conflict-auditor: Logical consistency auditing
- privacy-detector: Privacy leak detection agent
- compare-claims: Claim comparison functionality
- web-opinion-extractor: Opinion extraction with bias analysis

┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. Get Effective Few-Shot Examples                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│ Endpoint:  GET /{agent_type}                                                │
│ Output:    {                                                                │
│              "agent_type": "privacy-detector",                              │
│              "few_shots": "string or dict",                                 │
│              "is_custom": true/false                                        │
│            }                                                                │

│ 2. Set Custom Few-Shot Examples                                            │

│ Input:     {                                                                │
│              "custom_few_shots": "string or dict"                           │
│            }                                                                │
│ Output:    {                                                                │
│              "message": "Custom few-shot examples set successfully",        │
│              "agent_type": "privacy-detector"                               │
│            }                                                                │
│ Use:       Set custom few-shot examples for an agent (persists across      │
│            restarts)                                                        │

│ 3. Get Current Custom Few-Shot Examples                                    │

│              "agent_type": "privacy-detector",                              │

│            }                                                                │
│ Use:       Get currently set custom few-shot examples or null if not set   │

┌─────────────────────────────────────────────────────────────────────────────┐
