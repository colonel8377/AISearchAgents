🎯 Few-shot Management

The platform provides comprehensive few-shot learning management for all AI agents. Each agent supports customizable few-shot examples that persist across API calls.

Supported Agents

  • nudge-collapse: Multi-turn conversation examples
  • demographic-evaluator: Perspective-based judgment examples
  • summarizer: Summary format examples
  • bot-creator: Bot configuration examples
  • content-extractor: Content extraction patterns
  • claim-atomizer: Claim decomposition examples
  • conflict-auditor: Conflict analysis examples
  • web-opinion-extractor: Opinion classification examples

Management Endpoints

# Get effective few-shot examples (custom if set, otherwise default) GET /api/v1/shots/{agent} # Set custom few-shot examples POST /api/v1/shots/{agent}/custom # Get current custom shots GET /api/v1/shots/{agent}/custom # Reset to default shots DELETE /api/v1/shots/{agent}/custom

Usage in API Calls

# Enable few-shot learning POST /api/v1/content/atomize { "text": "Content to atomize", "atomization_type": "claims", "use_few_shots": true } # Disable few-shot learning POST /api/v1/content/atomize { "text": "Content to atomize", "atomization_type": "claims", "use_few_shots": false }

🔧 Configuration

# Required environment variables OPENAI_API_KEY=your_key OPENAI_MODEL=gpt-3.5-turbo # Embedding configuration (supports multiple providers) EMBEDDING_PROVIDER=openai # openai, qwen, gemini, deepseek EMBEDDING_MODEL=text-embedding-ada-002 EMBEDDING_API_KEY= # Leave empty to use OPENAI_API_KEY # Optional settings API_HOST=0.0.0.0 API_PORT=8000 VECTOR_STORE_TYPE=chroma
